# Акселератор ИТМО — Bootstrap 3.3.6

Адаптивная версия главной страницы по мотивам https://accel.itmo.ru/.

Откройте `dist/index.html` в браузере. Сборка и установка пакетов не нужны.
В архиве исходников `index.html` лежит в корне.

- Bootstrap **3.3.6** и jQuery **1.12.4** подключены локально.
- `assets/style.css` — оформление и адаптивные стили.
- `assets/app.js` — поведение мобильного меню и слайдера.
- Сетка: `container`, `row`, `col-*`; компоненты: navbar, dropdown, collapse, carousel, alert.
- Изображения и шрифты загружены с сайта-образца и доступны локально.
- Кнопки программ, заявок и социальных сетей ведут на реальные внешние страницы ИТМО. Собственного сервера приема заявок нет.
- Воссозданы основные разделы главной страницы; внутренние страницы не копируются.

Материалы и фирменная символика принадлежат их правообладателям.
